# polynome — Technical Plan

## Overview

**polynome** is a browser-based polyrhythmic grid sequencer inspired by monome grid controllers. It ships as a static site deployable on GitHub Pages. All audio is pre-generated at build time using Python; the browser runtime only does playback, effects, and UI.

Five modes, each with a distinct sonic identity:

| Mode | Concept | Sound reference |
|------|---------|-----------------|
| `original` | Exact replication of a monome grid video | Analysis of source video |
| `texture` | Deep, gritty electronic | Superpoze, Scratch Massive, Fakear |
| `clear` | Crystalline analog synthesis | Wendy Carlos — Switched-On Bach, Tron, Beauty in the Beast |
| `voices` | Extended vocal technique | Roomful of Teeth, Meredith Monk |
| `speech` | Phoneme-driven percussive speech | Laurie Anderson, Holly Herndon |

### Deployment

GitHub Pages serves everything from the repo root (or `/docs`). The `build/` directory is development-only. The `assets/` directory contains pre-generated `.ogg` files committed to the repo. Total asset budget: ~5MB (OGG at quality 3, ~30KB per 2-3s stereo file, ~160 files per mode, 5 modes ≈ 5MB).

GitHub Actions workflow: on push to `main`, deploy root as static site. No build step in CI — assets are pre-committed. If assets need regeneration, developer runs `python build/build.py` locally and commits the output.

### 2.2 Sequencer Logic

Unchanged from current implementation:

- **Main grids**: polyrhythmic. Column determines period (`cols - col`). Lights spawn and travel left→right. Sound fires when light hits rightmost column. Offset set on press so a light starts at rightmost column immediately. `mod(step - offset - j, period) === 0` for light at column `j`. `mod(step - offset - (cols-1), period) === 0` for sound trigger.
- **Melody grids**: linear score. Cursor advances left→right every `melN` main steps. Sound fires when cursor lands on a pressed cell. Wraps at `totalMelCols`.
- **3-state cells**: off → half (vol 0.5) → full (vol 1.0) → off.
- **4 visual states**: `OFF`, `LIT` (light passing), `ON_HALF`, `ON_FULL`, `TRIG` (sound firing at rightmost col for main, cursor-on-cell for melody).
- **Pattern system**: 8 slots, save/load/auto-cycle/crossfade transitions.

### 2.3 Audio Playback

```
BufferSource → dry GainNode → masterCompressor → destination
            → delay send GainNode → ping-pong delay → masterCompressor
            → reverb send GainNode → convolution reverb → masterCompressor
```

All audio is pre-rendered `.ogg` files loaded as `AudioBuffer` via `fetch()` + `decodeAudioData()`. Zero `OscillatorNode`, zero `OfflineAudioContext`. Playback is exclusively `BufferSource.start(time)`.

The effects chain (delay, reverb, compressor) remains real-time because it depends on the live mix of concurrent notes.

### 2.4 Buffer Loading (`js/loader.js`)

```js
async function loadMode(modeName) {
  const manifest = await fetch(`assets/${modeName}/manifest.json`).then(r => r.json());
  const buffers = {};
  const promises = [];
  
  for (const inst of manifest.instruments) {
    buffers[inst.id] = new Array(inst.pitchCount);
    for (let i = 0; i < inst.pitchCount; i++) {
      const url = `assets/${modeName}/${inst.id}_${i}.ogg`;
      promises.push(
        fetch(url)
          .then(r => r.arrayBuffer())
          .then(ab => audioCtx.decodeAudioData(ab))
          .then(buf => { buffers[inst.id][i] = buf; })

  }
```

## 3. Python Build System

### 3.1 Common DSP Library (`build/common.py`)

```python
import numpy as np
from scipy.signal import sosfilt, butter, sosfiltfilt
from scipy.io import wavfile
import subprocess, json, os

SR = 44100

def sine(freq, dur, sr=SR):
    """Pure sine oscillator."""
    t = np.arange(int(sr * dur)) / sr
    return np.sin(2 * np.pi * freq * t)

def saw(freq, dur, sr=SR, num_harmonics=30):
    """Band-limited sawtooth via additive synthesis."""
    t = np.arange(int(sr * dur)) / sr
    out = np.zeros_like(t)
    for k in range(1, num_harmonics + 1):
        if k * freq > sr / 2:
            break
        out += ((-1) ** (k + 1)) * np.sin(2 * np.pi * k * freq * t) / k
    return out * (2 / np.pi)

def pulse(freq, dur, pw=0.5, sr=SR, num_harmonics=30):
    """Band-limited pulse wave."""
    t = np.arange(int(sr * dur)) / sr
    out = np.zeros_like(t)
    for k in range(1, num_harmonics + 1):
        if k * freq > sr / 2:
            break
        out += np.sin(np.pi * k * pw) * np.sin(2 * np.pi * k * freq * t) / k
    return out * (4 / np.pi)

def noise(dur, sr=SR):
    """White noise."""
    return np.random.uniform(-1, 1, int(sr * dur))

def stereo_noise(dur, sr=SR):
    """Stereo white noise."""
    return np.column_stack([noise(dur, sr), noise(dur, sr)])

def env_adsr(dur, attack, decay, sustain, release, sr=SR):
    """ADSR envelope, returns array of length int(sr*dur)."""
    n = int(sr * dur)
    a = int(sr * attack)
    d = int(sr * decay)
    r = int(sr * release)
    s = max(0, n - a - d - r)
    env = np.concatenate([
        np.linspace(0, 1, a),
        np.linspace(1, sustain, d),
        np.full(s, sustain),
        np.linspace(sustain, 0, r),
    ])
    return env[:n]

def env_exp_decay(dur, attack_ms, decay_time, sr=SR):
    """Exponential decay envelope."""
    n = int(sr * dur)
    a = int(sr * attack_ms / 1000)
    env = np.zeros(n)
    env[:a] = np.linspace(0, 1, a)
    t = np.arange(n - a) / sr
    env[a:] = np.exp(-t / decay_time)
    return env

def lowpass(sig, freq, sr=SR, order=4):
    """Butterworth lowpass."""
    sos = butter(order, freq, btype='low', fs=sr, output='sos')
    return sosfilt(sos, sig)

def highpass(sig, freq, sr=SR, order=4):
    sos = butter(order, freq, btype='high', fs=sr, output='sos')
    return sosfilt(sos, sig)

def bandpass(sig, low, high, sr=SR, order=2):
    sos = butter(order, [low, high], btype='band', fs=sr, output='sos')
    return sosfilt(sos, sig)

def filter_sweep(sig, start_freq, end_freq, sr=SR, order=4, block_size=256):
    """Time-varying lowpass filter sweep using block processing."""
    n = len(sig)
    out = np.zeros(n)
    freqs = np.logspace(np.log10(start_freq), np.log10(end_freq), n // block_size + 1)
    freqs = np.clip(freqs, 20, sr / 2 - 100)
    zi = None
    for i, fc in enumerate(freqs):
        start = i * block_size
        end = min(start + block_size, n)
        if start >= n:
            break
        sos = butter(order, fc, btype='low', fs=sr, output='sos')
        if zi is None:
            block, zi = sosfilt(sos, sig[start:end], zi=np.zeros((sos.shape[0], 2)))
        else:
            block, zi = sosfilt(sos, sig[start:end], zi=zi)
        out[start:end] = block
    return out

def wavefold(sig, folds=3):
    """Triangle wavefolding."""
    x = sig * folds
    return (4 / np.pi) * np.arcsin(np.sin(np.pi * x / 2))

def tanh_saturate(sig, drive=4):
    return np.tanh(sig * drive) / np.tanh(drive)

def asymmetric_saturate(sig, drive=2, asymmetry=0.15):
    """Tape-like asymmetric saturation. Creates even harmonics."""
    pos = np.tanh(sig * drive * (1 + asymmetry)) / (1 + asymmetry)
    neg = np.tanh(sig * drive * (1 - asymmetry)) / (1 - asymmetry)
    return np.where(sig >= 0, pos, neg)

def bitcrush(sig, bits=10, downsample=3):
    step = 2 ** (-(bits - 1))
    crushed = np.round(sig / step) * step
    if downsample > 1:
        held = crushed.copy()
        for i in range(len(held)):
            if i % downsample != 0:
                held[i] = held[i - 1]
        return held
    return crushed

def comb_filter(sig, delay_samples, feedback=0.7, lp_freq=None, sr=SR):
    """Comb filter (Karplus-Strong like) with optional LP in feedback."""
    n = len(sig)
    out = np.zeros(n)
    buf = np.zeros(delay_samples)
    p = 0
    for i in range(n):
        out[i] = sig[i] + buf[p] * feedback
        buf[p] = out[i]
        if lp_freq:
            # simple one-pole LP in feedback
            if p > 0:
                alpha = 1 - np.exp(-2 * np.pi * lp_freq / sr)
                buf[p] = alpha * buf[p] + (1 - alpha) * buf[(p - 1) % delay_samples]
        p = (p + 1) % delay_samples
    return out

def normalize(sig, peak=0.85):
    mx = np.max(np.abs(sig))
    if mx > 0:
        sig = sig * (peak / mx)
    return sig

def fade_in(sig, ms, sr=SR):
    n = int(sr * ms / 1000)
    sig[:n] *= np.linspace(0, 1, n)
    return sig

def fade_out(sig, ms, sr=SR):
    n = int(sr * ms / 1000)
    sig[-n:] *= np.linspace(1, 0, n)
    return sig

def to_stereo(mono, pan=0):
    """Pan mono signal. pan in [-1, 1]."""
    l = mono * np.sqrt((1 - pan) / 2)
    r = mono * np.sqrt((1 + pan) / 2)
    return np.column_stack([l, r])

def mix_stereo(*signals):
    """Sum stereo signals, padding to max length."""
    maxlen = max(len(s) for s in signals)
    out = np.zeros((maxlen, 2))
    for s in signals:
        out[:len(s)] += s
    return out

def export_ogg(stereo_signal, path, sr=SR):
    """Export as OGG via ffmpeg (or scipy wav as fallback)."""
    wav_path = path.replace('.ogg', '.wav')
    sig16 = np.clip(stereo_signal, -1, 1)
    sig16 = (sig16 * 32767).astype(np.int16)
    wavfile.write(wav_path, sr, sig16)
    if path.endswith('.ogg'):
        subprocess.run([
            'ffmpeg', '-y', '-i', wav_path,
            '-c:a', 'libvorbis', '-q:a', '3',
            path
        ], capture_output=True)
        os.remove(wav_path)

def write_manifest(out_dir, instruments, fx_config):
    """Write manifest.json for JS loader."""
    manifest = {
        'instruments': [
            {'id': inst['id'], 'label': inst['label'], 'pitchCount': inst['pitchCount'],
             'type': inst.get('type', 'main')}
            for inst in instruments
        ],
        'fx': fx_config,
    }
    with open(os.path.join(out_dir, 'manifest.json'), 'w') as f:
        json.dump(manifest, f, indent=2)
```

### 5.3 Python Generation

Each instrument function takes `(freq, sr)` and returns a stereo numpy array. Example for `sub`:

```python
def gen_sub(freq, sr=44100):
    f = freq * 0.25  # 2 octaves down
    dur = 2.0
    n = int(sr * dur)
    
    # 4 saws + 4 pulses with per-voice drift
    voices = []
    detunes = [-28, -18, -8, -3, 3, 8, 18, 28]
    pans = [-0.9, -0.6, -0.3, -0.1, 0.1, 0.3, 0.6, 0.9]
    drift_rates = [0.13, 0.09, 0.17, 0.11, 0.14, 0.08, 0.16, 0.1]
    
    for i in range(8):
        # Time-varying frequency with drift
        t = np.arange(n) / sr
        drift = np.sin(2 * np.pi * drift_rates[i] * t) * (drift_rates[i] * 20)
        inst_freq = f * (2 ** ((detunes[i] + drift) / 1200))
        
        # Phase accumulation for pitch-varying oscillator
        phase = np.cumsum(inst_freq / sr)
        if i < 4:
            voice = 2 * (phase % 1) - 1  # naive saw (will be filtered/folded anyway)
        else:
            voice = np.where(phase % 1 < 0.5, 1, -1)  # pulse
        
        gain = 0.14 if i < 4 else 0.10
        voices.append(to_stereo(voice * gain, pans[i]))
    
    mix = mix_stereo(*voices) * 0.4
    
    # Asymmetric wavefold
    for ch in range(2):
        x = mix[:, ch] * 3
        folded = (4 / np.pi) * np.arcsin(np.sin(np.pi * x / 2))
        mix[:, ch] = np.where(x > 0, folded * 0.85, folded)
    
    # Tanh saturation
    mix = np.tanh(mix * 6) / np.tanh(6)
    
    # Filter sweep
    for ch in range(2):
        mix[:, ch] = filter_sweep(mix[:, ch], f * 16, f * 1.3, sr, order=4)
    
    # Sub sine with slow AM
    sub_sig = sine(f, dur, sr)
    am = 0.5 + 0.5 * np.sin(2 * np.pi * 0.25 * np.arange(n) / sr)
    sub_stereo = to_stereo(sub_sig * am * 0.5, 0)
    
    # 50Hz hum
    hum = to_stereo(sine(50, dur, sr) * 0.06, 0)
    
    # Noise layer
    noise_sig = noise(0.5, sr)
    noise_sig = wavefold(noise_sig, 2)
    noise_sig = lowpass(noise_sig, f * 8, sr)
    noise_env = env_exp_decay(0.5, 1, 0.15, sr)
    noise_sig *= noise_env * 0.35
    noise_stereo = to_stereo(noise_sig, 0)
    
    # Combine
    result = mix_stereo(mix[:n], sub_stereo[:n], hum[:n], noise_stereo)
    
    # Envelope
    env = env_exp_decay(dur, 3, 0.8, sr)
    result *= env[:, np.newaxis]
    
    return result
```

### 6.2 Key Technical Element: Moog Ladder Filter

The defining sound of Carlos's work. Must be implemented properly.

Huovilainen's improved model (2004), per-sample:

```python
def moog_ladder(sig, cutoff_hz, resonance, sr=44100):
    """
    4-pole resonant ladder filter.
    resonance: 0 to ~4 (self-oscillation at 4).
    cutoff_hz: can be array for modulation.
    """
    if isinstance(cutoff_hz, (int, float)):
        cutoff_hz = np.full(len(sig), cutoff_hz)
    
    # State: 4 integrator stages
    s = [0.0, 0.0, 0.0, 0.0]
    out = np.zeros(len(sig))
    
    for i in range(len(sig)):
        fc = cutoff_hz[i]
        # Frequency warping
        g = 1 - np.exp(-2 * np.pi * fc / sr)
        
        # Feedback with nonlinear saturation
        feedback = resonance * np.tanh(s[3])
        
        # Input with feedback
        x = sig[i] - feedback
        x = np.tanh(x)  # input nonlinearity
        
        # 4 cascaded one-pole sections
        for stage in range(4):
            s[stage] += g * (x - s[stage])
            x = s[stage]
        
        out[i] = s[3]
    
    return out
```

This is O(n) per-sample processing — slow in Python. For a 3s buffer at 44100Hz = 132,300 samples × 4 stages = ~500K operations. Takes ~2s in pure Python. Acceptable for a build step. Can be accelerated with `numba.jit` if needed.

## 7. Mode: `voices`

### 7.1 Sound Reference

Roomful of Teeth: overtone singing, throat singing, yodeling, Inuit vocal games, belting. Meredith Monk: extended vocal textures, layered syllables.

### 7.2 Vocal Synthesis Architecture

No external audio dependencies. Everything synthesized from a glottal pulse model + formant filters.

#### Glottal Source

Rosenberg model — the standard acoustic model of vocal cord vibration:

```python
def glottal_pulse(f0, dur, sr=44100, open_quotient=0.6):
    """
    Rosenberg glottal pulse model.
    open_quotient: fraction of cycle where glottis is open (0.5-0.8).
    """
    n = int(sr * dur)
    t = np.arange(n) / sr
    
    # Add jitter (pitch perturbation) and shimmer (amplitude perturbation)
    jitter = np.cumsum(np.random.normal(0, f0 * 0.005, n)) / sr
    phase = np.cumsum((f0 + jitter * f0 * 0.3) / sr)
    cycle_pos = phase % 1  # position within each glottal cycle
    
    # Rosenberg waveform
    oq = open_quotient
    pulse = np.where(
        cycle_pos < oq,
        3 * (cycle_pos / oq) ** 2 - 2 * (cycle_pos / oq) ** 3,
        0
    )
    
    # Shimmer
    shimmer = 1 + np.random.normal(0, 0.03, n)
    pulse *= shimmer
    
    # Spectral tilt: differentiate for more natural vocal spectrum
    pulse = np.diff(pulse, prepend=0)
    
    return pulse
```

#### Formant Filter

Standard vowel formant frequencies (Hz):

| Vowel | F1 | F2 | F3 | F4 |
|-------|-----|------|------|------|
| /a/ (father) | 730 | 1090 | 2440 | 3400 |
| /i/ (see) | 270 | 2290 | 3010 | 3300 |
| /u/ (boot) | 300 | 870 | 2240 | 3200 |
| /e/ (bed) | 530 | 1840 | 2480 | 3320 |
| /o/ (bought) | 570 | 840 | 2410 | 3400 |

```python
def formant_filter(sig, formants, sr=44100):
    """
    Apply parallel formant filter bank.
    formants: list of (freq_hz, bandwidth_hz, gain_db)
    """
    out = np.zeros_like(sig)
    for f, bw, gain in formants:
        sos = butter(2, [max(20, f - bw/2), min(sr/2 - 100, f + bw/2)], 
                     btype='band', fs=sr, output='sos')
        filtered = sosfilt(sos, sig) * (10 ** (gain / 20))
        out += filtered
    return out
```

### 7.4 Natural Vocal Character

Critical additions to avoid robotic sound:
- **Vibrato**: 5–6Hz sine on f0, depth 30–50 cents (configurable per instrument)
- **Jitter**: random pitch fluctuation ±0.5% per glottal cycle
- **Shimmer**: random amplitude fluctuation ±3% per cycle
- **Formant transition**: for longer notes, slowly morph between two vowel shapes (LFO on formant frequencies at 0.3Hz)
- **Breathiness**: mix 5–15% filtered noise into all vocal sounds (not just `breath` instrument)

## 8. Mode: `speech`

### 8.1 Strategy

Use `espeak-ng` (rule-based TTS, no ML, ~2MB, available on all platforms) to generate phoneme audio segments. Each phoneme becomes a tunable percussive/tonal element.

Why `espeak-ng` over `piper`:
- Zero ML dependencies
- Deterministic output
- Tiny
- Available via `apt install espeak-ng` or `pip install py-espeak-ng`
- Can output at specific pitch and speed
- Can generate individual phonemes

### 8.2 Phoneme Generation

```python
import subprocess
import numpy as np
from scipy.io import wavfile

PHONEMES = {
    # Vowels
    'aa': 'a', 'ee': 'i', 'oo': 'u', 'eh': 'e', 'oh': 'o',
    # Plosives
    'b': 'b', 'd': 'd', 'g': 'g', 'k': 'k', 'p': 'p', 't': 't',
    # Fricatives
    's': 's', 'sh': 'S', 'f': 'f', 'z': 'z', 'v': 'v',
    # Nasals
    'm': 'm', 'n': 'n', 'ng': 'N',
    # Liquids
    'l': 'l', 'r': 'r',
}

def generate_phoneme(ipa_symbol, pitch_hz=150, sr=44100):
    """Generate a single phoneme using espeak-ng."""
    # espeak uses pitch in range 0-99, need to convert
    # Default pitch 50 ≈ 150Hz for male voice
    pitch_param = int(50 * (pitch_hz / 150))
    pitch_param = max(0, min(99, pitch_param))
    
    tmp_wav = '/tmp/phoneme.wav'
    subprocess.run([
        'espeak-ng',
        f'[[{ipa_symbol}]]',      # phoneme in double brackets
        '-v', 'en',                # English voice
        '-p', str(pitch_param),    # pitch
        '-s', '80',                # slow speed for clear phoneme
        '--pho',                   # phoneme mode
        '-w', tmp_wav,
    ], capture_output=True)
    
    rate, data = wavfile.read(tmp_wav)
    # Resample if needed
    if rate != sr:
        from scipy.signal import resample
        data = resample(data, int(len(data) * sr / rate))
    
    return data.astype(float) / 32768
```

### 8.3 Post-Processing Pipeline

Raw espeak output sounds robotic. Post-processing to make it musical:

1. **Trim**: remove silence padding
2. **Time-stretch**: normalize duration to ~200ms (all phonemes same length)
3. **Pitch-shift**: create 8 pitch variants per phoneme using `scipy` resampling
4. **Formant preservation**: when pitch-shifting, resample then apply formant correction via spectral envelope matching (vocoder-like)
5. **Grain layering**: for vowels, overlay 3 slightly offset copies (±5ms) for thickness
6. **Saturation**: light `tanh(x * 1.3)` for warmth
7. **Fade**: 5ms in, 30ms out

### 8.4 Instruments

Group phonemes by articulatory class:

| ID | Phonemes | Character |
|----|----------|-----------|
| `vowels` | aa, ee, oo, eh, oh | Tonal, sustained, pitched |
| `clicks` | b, d, g, k, p, t | Percussive plosives, short, pitched by formant shift |
| `hiss` | s, sh, f, z, v | Noise-like fricatives, textural |
| `nasal` | m, n, ng | Warm, humming, tonal |
| `liquid` | l, r | Flowing, between tonal and noise |

Each instrument = 8 pitch variants of each phoneme in the group. Row selects the phoneme, pitch-shifted to match the row's frequency.

Alternative approach for melody grid: use full syllables. `ba`, `da`, `la`, `ma`, `na`, `pa`, `ta`, `wa` — 8 syllables, one per row. More recognizable as speech.

```js
function buildEffectsChain(config) {
  // Compressor
  const comp = ctx.createDynamicsCompressor();
  comp.threshold.value = config.compThreshold;   // -18 for clear, -12 for texture
  comp.ratio.value = config.compRatio;            // 3 for clear, 8 for texture

  // OR: generated in JS from parameters (current approach)
  // The IR generation is cheap enough to stay in JS
  const irLen = Math.round(ctx.sampleRate * config.reverbLength);
  const irBuf = ctx.createBuffer(2, irLen, ctx.sampleRate);
  for (let ch = 0; ch < 2; ch++) {
    const d = irBuf.getChannelData(ch);
    for (let i = 0; i < irLen; i++)
      d[i] = (Math.random() * 2 - 1) * Math.pow(1 - i/irLen, 2.5);
    // Darken: LP averaging
    const dark = config.reverbDark;
    for (let i = 1; i < irLen; i++)
      d[i] = d[i] * (1 - dark) + d[i-1] * dark;
  }
  
  // Ping-pong delay with feedback LP
  // delay times, feedback, LP freq all from config
  // ...
}
```
